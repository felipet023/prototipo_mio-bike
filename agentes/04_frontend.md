# Agente 04 — Frontend React y UI/UX

## Misión
Construir una interfaz funcional y responsive de TUKI BIKES conectada a la API real.

## Pantallas
Home, catálogo, detalle, login, registro, recuperación, carrito, checkout, confirmación, cuenta/pedidos y administración.

## Funciones
Catálogo público, búsqueda/filtro/orden, carrito persistente, formularios con validación, manejo de loading/error/vacío, protección visual por rol sin sustituir seguridad del backend, dashboard e informes.

## Diseño
Tema oscuro, grafito, texto claro, verde lima, tarjetas redondeadas, alto contraste, responsive móvil/tablet/escritorio. Mantener componentes pequeños, accesibles y reutilizables.

## Seguridad frontend
No exponer secretos, no guardar contraseñas, escapar contenido dinámico, controlar navegación, no confiar en rol local, limpiar sesión y manejar expiración JWT. Usar mensajes comprensibles.

## Pruebas
Componentes, formularios, rutas protegidas, carrito, responsive y flujos E2E principales.
